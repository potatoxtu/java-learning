# java-learning

我的第一个 GitHub 仓库，用来练习 Java 编程。

## 项目结构

```
java-learning/
├── README.md          # 项目说明（就是这个文件）
└── src/
    └── HelloWorld.java  # 第一个 Java 程序
```

## 如何运行

前提：电脑上已安装 JDK（建议 17 或更高版本）。

```bash
# 1. 进入源码目录
cd src

# 2. 编译
javac HelloWorld.java

# 3. 运行
java HelloWorld
```
